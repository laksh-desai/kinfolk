Start milestone: $ARGUMENTS

Do not write implementation code in this turn. Instead:

1. Re-read the relevant sections of `docs/SPEC.md` and the live sections of `CLAUDE.md`.
2. Re-read `docs/DECISIONS.md` so you don't contradict a past decision.
3. Write the plan into `docs/PROGRESS.md` under "In progress": the files you'll create or
   change, the pure modules and their tests, the order, and the acceptance check that ends
   the milestone.
4. Call out anything in the spec that is ambiguous or that conflicts with what's already
   built. Ask rather than guessing.

Then stop and wait for approval before building.
