# Defect verification

Each item is a real, observed failure in the product being replaced (`docs/SPEC.md` §6).
Mark done only with a test name, a file path, or a one-line design reason that makes the
defect structurally impossible. "N/A" needs a justification.

Status: ☑ verified · ◐ partly verified (evidence so far + what is still unproven) · ☐ not yet

| 23 | One ~1MB bundle, SDKs loaded everywhere | ◐ | Every page is a `lazy()` route; every M6 person screen is its own chunk. The budget is held by `apps/web/scripts/bundleBudget.mjs` (`pnpm --filter web budget`, run in CI on every push): it walks Vite's manifest and fails the build if the initial route or any lazy route with everything it pulls in exceeds 200 KB gzip. Build 2026-09-30: initial 153.7 KB, heaviest route (the tree) 197.4 KB — the tree had reached 208 KB unnoticed between hand measurements, fixed by loading the exporters and the delete dialog on demand.
